# UK-focused sources (checked list)

Cite only these sources in a starter pack, with their links. The publisher last checked that each link opened on 26 November 2026. Links can change, so tell the user to open the link and check it is current before relying on it. Improvement Guru is not affiliated with or endorsed by any of these organisations.

| Source | Organisation | Link | Use it for |
| --- | --- | --- | --- |
| Model for Improvement | Institute for Healthcare Improvement (IHI) | https://www.ihi.org/library/model-for-improvement | The three questions, aims, measures and PDSA cycles. A portable method used alongside NHS local governance. |
| A guide to quality improvement tools | Healthcare Quality Improvement Partnership (HQIP) | https://www.hqip.org.uk/guidance/guide-to-quality-improvement-methods/ | An overview of QI tools, including PDSA, the Model for Improvement, process mapping, statistical process control (SPC) and root-cause analysis. |
| Best Practice in Clinical Audit | Healthcare Quality Improvement Partnership (HQIP) | https://www.hqip.org.uk/guidance/best-practice-in-clinical-audit/ | Telling QI apart from clinical audit; the audit cycle, standards and re-audit. |
| Improvement resources | NHS England, NHS IMPACT | https://www.england.nhs.uk/nhsimpact/improvement-resources/ | NHS improvement guides, data resources, QI toolkits and training links. |

## Signpost only

- **Patient Safety Incident Response Framework (PSIRF)**, NHS England: https://www.england.nhs.uk/long-read/patient-safety-incident-response-framework/. Incident learning is outside this workflow. Use this link only to point incident questions to the local PSIRF route.

## Not in this list: always "To check locally"

- Specialty standards, such as a Royal College or national clinical audit standard.
- NICE guidance relevant to the pathway.
- Local trust, health board or practice policies and guidelines.
- The local QI or audit registration process.
